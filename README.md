# GitHub Copilot Lernreise

> Mein Lernweg mit GitHub Copilot

## Über mich

Ich bin Masterstudent im Wirtschaftsingenieurwesen mit Schwerpunkt Energie- und Umwelttechnik an der Universität Rostock. Neben meinem Studium arbeite ich als Baustoffprüfer. In dieser Rolle treffe ich täglich auf praktische Aufgaben, bei denen Daten, Muster und wiederkehrende Prozesse eine große Rolle spielen.

Seit ich GitHub Copilot nutze, interessiere ich mich zunehmend dafür, wie ich durch die Kombination aus Programmieren, Automatisierung und Datenanalyse Alltagstätigkeiten effizienter gestalten kann. Mein Ziel ist es, mit Hilfe von Copilot kleine, aber nützliche Lösungen für reale Arbeitsaufgaben zu entwickeln – insbesondere bei der Auswertung und Verarbeitung von Prüfdaten.

## Ziele

Ich möchte mit GitHub Copilot lernen, wie ich:

- häufig wiederkehrende Aufgaben automatisieren kann,
- Daten aus Prüfprozessen sinnvoll auswerten und aufbereiten kann,
- kleine Programme, Skripte oder Automatisierungen für den Arbeitsalltag entwickeln kann,
- mit KI-gestützter Programmierung effizienter arbeiten und schneller lernen kann,
- meine technischen Fähigkeiten gezielt ausbauen und in der Praxis anwenden kann.

Im Fokus stehen dabei vor allem Anwendungen, die im Alltag hilfreich sind, zum Beispiel:

- Auswertung von Prüfdaten,
- Bereinigung und Strukturierung von Messdaten,
- vereinfachte Analyse von Ergebnissen,
- Automatisierung von wiederkehrenden Arbeitsschritten,
- Erstellung kleiner Werkzeuge zur Unterstützung im beruflichen Kontext.

## Lernfortschritt

Hier dokumentiere ich meinen Fortschritt beim Lernen mit GitHub Copilot. Die einzelnen Punkte dienen als Checkliste für meinen Weg von der ersten Idee bis zur nutzbaren Automatisierung.

- [ ] Grundlagen der Programmierung verstehen und sicher anwenden
- [ ] Git und GitHub kennenlernen und korrekt verwenden
- [ ] GitHub Copilot sinnvoll und verantwortungsvoll einsetzen
- [ ] Einfache Skripte für Datenverarbeitung schreiben
- [ ] Tabellen, CSV-Dateien und Messdaten analysieren
- [ ] Wiederkehrende Aufgaben in kleine Automatisierungen überführen
- [ ] Praktische Anwendungsfälle aus dem Alltag identifizieren
- [ ] Code verständlich strukturieren und dokumentieren
- [ ] Fehler erkennen, analysieren und gezielt lösen
- [ ] Kleine Projekte mit echtem Nutzen für die Arbeit umsetzen
- [ ] Lernprozesse reflektieren und dokumentieren
- [ ] Lösungen weiterentwickeln, verbessern und erweitern

### Aktueller Fokus
